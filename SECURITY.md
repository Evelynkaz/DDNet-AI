# Безопасность · Security

Если вы нашли уязвимость (например, в веб-панели, запускателе или клиенте), не публикуйте её в открытых Issues.
Сообщите приватно через GitHub: вкладка **Security → Report a vulnerability** этого репозитория.

Что важно для этого проекта:
- веб-панель работает за Caddy с HTTPS и паролем, бот и сайт слушают только 127.0.0.1;
- запуск бота с сайта проверяет отдельная root-программа, которая принимает только булевы поля и значения из
  закрытых списков;
- бот не обходит кики и баны и не пишет в игровой чат сам.

*English: please report vulnerabilities privately via GitHub's “Report a vulnerability” on the Security tab, not in
public issues.*
