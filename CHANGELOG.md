## [0.2.0] — 2026-10-09

### Добавлено
- **Windows (задача 5.5a, D-047, D-127).** Бот собирается и играет на Windows 10/11 x86-64 с теми же числами физики и
  планировщика, что на Linux: `crates/ddai-libm` — побитно точные порты `sinf`, `cosf`, `atanf`, `atan2f`, `powf`, `hypotf`,
  `log`, `atan2`, `pow`, `hypot` из glibc 2.39 (сверены с glibc: все 2³² входа для `sinf`/`cosf`/`atanf`, ≥ 10⁹ проб для
  остальных) и свой точный `fma`. Вне glibc `fma` C-библиотеки не используется — это запас надёжности: на Windows его
  ошибок не нашли, но его путь для процессоров без FMA в CI не проверить. Перед игрой бот проверяет математику и
  отказывается играть, если она даёт не те биты (первый прогон CI на Windows поймал так ошибку в самой самопроверке:
  её входы для `log` строились через системную `exp2`).
  `crates/ddai-os` — шов ОС: каталог данных `%USERPROFILE%\ddnet-ai\data`, секреты только для пользователя (ACL по SID).
  Задача CI `windows` на `windows-latest` собирает, гоняет clippy и все тесты и собирает `ddnet-ai.exe`.
- **Исправления дуэли** (3.23, D-121, E-038): `--duel-fixes off|all|static,counter,finish`; «добивание» — go,
  «мёртвая точка» — почти go, «контратака» — no-go. На сайте — переключатель «Исправления дуэли» (5.18, D-129).
- **Потоки поиска** (5.17, D-125): `--search-threads 1–4`; кнопка «Дуэль» ставит 3 (+50% кандидатов на тихой машине).
- **Ходы людей из демок** (3.24, D-122, E-039): настоящие вводы соперников (`Sv_PreInput`) из демок, набор данных и
  разбор поведения людей после блока; предсказатель и имитация на них — no-go, но разбор задаёт следующие задачи.
- **Приоритет процессора** для бота (4.14, D-124): свой слайс systemd, `tools/lowprio.sh` для тяжёлой работы.

### Изменено
- **Скорость** (4.13, D-123, E-040): горячий путь решения быстрее, бит-в-бит; кандидатов на решение вживую p50 16 → 24–25.
- **Выключатели-маркеры** (`*.off`) срабатывают и тогда, когда путь нельзя прочитать — на всех ОС (общий
  `ddai_os::marker::is_present`; на Windows раньше молча не срабатывали бы).
- **Выкатка** (5.19, D-130): `deploy/install.sh` не ходит в apt, если Caddy уже стоит, ждёт блокировки apt и называет
  сломанный репозиторий; флаг `--skip-apt`.
- Адреса сторонних серверов убраны из кода, тестов и документации (9.2).

### Известные ограничения
- Windows: нет канала управления и моста «бот → сайт» (сокеты Unix), нет `launch`/systemd — это 5.5b; бот запускается из
  консоли (`ddnet-ai.exe play …`). Физика на Windows ≈ 7% медленнее, потому что каждая операция `fma` — программная.
- Сети мухи на Windows могут отличаться от Linux в последних битах (`exp`, `tanh`, `ln` из системы).
- Муха пока не превосходит контроль без коннектома.
- Под нагрузкой машины бот заметно слабеет: держите машину с ботом тихой.
- Веса, данные коннектома, карты и демки в релиз не входят.

## [0.1.0] — 2026-10-08

Первый релиз Rust-версии. Это изменённая версия [Wranked1/DDNet-AI](https://github.com/Wranked1/DDNet-AI)
(GPL-3.0), переписанная на Rust; старая TypeScript/Electron-версия удалена из дерева (последний коммит с ней —
`0311695`).

### Добавлено
- **Физика.** Побитно точный порт физики сервера DDNet 20.1 (`ddai-physics`), сверенный с C++: 0 расхождений на
  ≈ 57 млн ти-тиков; мир сервера со стадиями A и B (оружие, драггеры, турели, свет); читатель карт.
- **Клиент.** Протокол DDNet 0.6 с DDNet-расширениями, SOCKS5 с UDP, `/timeout`-код, точный цикл ввода по слотам,
  приём предварительных вводов сервера (`Sv_PreInput`, только приём).
- **Мозг.** Гибрид: CEM на точной физике, книга техник, модель соперника («зеркало»), удержанный блок и «Дожим»,
  вейблок и навигация Copy Love Box, умная политика самоубийств и распознавание дуэли 1 на 1 F-DDrace.
- **«Муха».** Сеть на коннектоме дрозофилы (MaleCNS v1.0): обучение BC/DAgger/ES/PPO, широкие считыватели, пилот
  нейронной модели в духе FlyGM — вместе с контролями без коннектома; результаты честно отрицательные (E-022…E-035).
- **Арена.** Офлайн-сравнения с парными сидами, правила раунда F-DDrace, «живое» зрение через снапшоты, модель лага,
  копия планировщика конкурента для замеров.
- **Сайт.** Веб-панель за Caddy с HTTPS и паролем: живая карта (WebGL2), запуск и остановка бота, кнопка «Дуэль»,
  браузер серверов и избранное, чат владельца, тишина машины, панель мухи.

### Живые результаты
- 08.10 — две дуэли против автора бота-конкурента (человек): обе выиграны; дуэль против другого игрока под нагрузкой
  машины — 9:10; 07.10 — тестовая дуэль против бота конкурента — 2:9. Разборы — `docs/research/duel-*.md`.

### Известные ограничения
- Под нагрузкой машины бот заметно слабеет: держите машину с ботом тихой.
- Муха пока не превосходит контроль без коннектома.
- Только Linux x86-64 (AVX2) в релизе 0.1.0. Windows-версия — в [Не выпущено] (задача 5.5a, D-127); упаковка и связь «бот → сайт» на Windows — 5.5b.
- Веса, данные коннектома, карты и демки в релиз не входят.
