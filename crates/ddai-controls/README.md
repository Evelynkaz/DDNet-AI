# ddai-controls — контроли MLP и GRU (задача 8.2, D-014)

Контроли, с которыми измеряется муха. Получают **ровно те же входы**, что муха (лучевая сетка и проприоцепция
`ddai_fly::encoder`, развёрнутые в вектор: 7 пространственных каналов × 48 направлений × 4 корзины + 3 скорости + 6
проприоцептивных = 1353 числа) и выдают **те же пять голов**: direction (3 логита), jump, hook, fire и прицел — вектор `(C, S)`,
угол которого `atan2(S, C)` оценивается тем же фон-Мизес-лоссом. Лосс, оптимизатор, расписание и данные — общие с мухой
(`ddai_fly::bc`, `ddai-train`); правило выбора действия то же, что у `FlyBrain` (argmax или выборка, `p ≥ 0,5`).

| Модуль | Что внутри |
|---|---|
| `features` | входной вектор (`input_dim`, `extract`) |
| `mlp` | `x → tanh(W1 x + b1) → головы`, без состояния; ручной forward/backward |
| `gru` | один слой GRU (PyTorch-конвенция, сброс применяется к рекуррентному члену кандидата) + линейные головы; BPTT |
| `net` | трейт `SeqNet` (плоский вектор параметров, окно с градиентом, онлайн-шаг), выходной слой |
| `bundle` | чекпоинт: вид, размеры, конфиг лучевой сетки, параметры, **пороги решений jump/hook/fire** (формат v2; v1 читается с порогами 0,5) (postcard + zstd, sha256, атомарная запись) |
| `brain` | `ControlBrain` (`Brain`; рекуррентное состояние сбрасывается в `reset`) и `ControlTemplate` (загрузить раз, мозг на партию) |

Размеры (E-005): «равные» — MLP h=5 (6 818 параметров) и GRU h=2 (8 166) против 6 440 обучаемых у мухи; «широкие» — MLP h=64
(87 176) и GRU h=32 (133 416) как потолок ёмкости на тех же входах. Точное равенство параметров невозможно: у мухи параметры
разделены по типам/парам типов, у контролей плотные (см. README `ddai-fly`, демо 7.3).

Тесты (`cargo test -p ddai-controls`): градиент MLP и BPTT GRU против конечных разностей, онлайн-шаг = окно, сброс состояния,
детерминизм, раскодирование действия, круговой обход чекпоинта (повреждённый/неверных размеров/NaN — ошибка), выборка по
сиду.
