# ddai-botctl

Задача 5.6. То, о чём бот (`ddai-bot`) и сайт (`ddai-web`) должны договариваться, в одном месте, чтобы они не расходились:

- `proto` — протокол канала управления v1 (`docs/formats.md` §26): `ControlRequest` / `ControlCommand` / `ControlReply`, закрытый список команд (**ни одной, что несёт текст в игровой чат, кроме `Say` — строки, набранной владельцем на сайте, задача 4.9, D-094**: текст проверяет `OwnerText::new`, `SayText` в `Debug` показывает только длину; сайт и протокол только *судят* строку — `OwnerText::check`, а сделать `OwnerText` может лишь держатель `OwnerChannel`, диспетчер бота), метки для аудита без текста и ников, проверки аргументов;
- `names` — свёртка имён D-021 (точное совпадение после нормализации);
- `relations` — списки friend / war / ignore / clanwar / clanfriend и их файл `relations.json` (его читает бот и пишет сайт; запись `0600`, атомарно).

Зависимостей от бота, клиента и сети нет (только `ddai-net` ради одной проверки текста чата: `OwnerText`, переэкспортирован из `proto`, чтобы сайт и бот проверяли одним и тем же кодом). `cargo test -p ddai-botctl`.
