# E-017 (задача 3.7b): сырые материалы разбора проигрышей гибрида

Скрипты — рабочие инструменты, пути вида `~/aiddnet/data/runs/E-017/` относятся к этой VM; сырые данные в репозиторий не входят. Описание метода и результат —
`../hybrid-losses.md`, эксперименты — `docs/EXPERIMENTS.md` E-017.

Конвейер:

1. `ddnet-ai arena run --config configs/arena/e017-diagnosis.toml --out …/diag --threads 3` — 1200 игр гибрид против фиксированного планировщика (сиды 1…400).
2. `cargo run --release -p ddai-env --example hybrid_losses -- --config configs/arena/e017-diagnosis.toml --games …/diag --out …/truth --select lost --threads 3`
   — воспроизводит проигранные игры под `ddai_planner::diag::DiagBrain` (хэш решений слота 0 сверяется с исходным прогоном) и пишет `truth.jsonl`: по игре — решения последних
   60 тиков с пулом и оценками, планом планировщика с места гибрида, прокрутками каждого плана в настоящем мире против настоящих вводов соперника, оценщиком с настоящими
   вводами соперника (`oracle`) и с планом «зеркала» (`oracle_mirror`). `--select won --limit N` — контроль по выигранным играм.
3. `classify2.py truth.jsonl` — дерево «спасающий план» (раздел 3 разбора): пробел генерации, выбор, модель соперника, оценщик, поздно; `classify.py` — форма из спеки
   (ход планировщика в пуле? оценка? настоящий мир?) с контролями; `examples.py` — аннотированные окна; `compare.py A_DIR B_DIR` — парное сравнение двух прогонов арены
   (засчитанные победы с интервалами Уилсона и точный McNemar); `mirror_accuracy.py` — насколько первый ввод модели соперника совпадает с настоящим (и с «держит ввод»); `stats.py` — Уилсон и McNemar.

Калибровка поиска (`configs/arena/e017-calibration.toml`), проверка силы после правки (`e017-fresh.toml`, `e017-regress.toml`, `e017-crowd.toml`,
`e017-mirror-quality.toml`, `e017-screen.toml`) — все на часах работы по умолчанию (1,25 мкс на ти-тик).
