# Сайт: как устроен образец и что мы портируем (задача 5.10)

Образец — текущий сайт оригинала (Wranked1/DDNet-AI, релиз 2026-10-02, ветка `origin/main`, клон в `~/aiddnet/ref/DDNet-AI-upstream`): `src/bot/{web,webPage,webView,webDraw,webMap,webAssets}.ts`,
`src/bot/page/{index.html,page.css,page.js}`, снимки `assets/en/*.png`. Код оригинала — GPL-3.0, наш репозиторий — его изменённый форк, поэтому портировать можно: уведомления сохранены, файлы помечены как изменённые,
код, происходящий из DDNet, несёт уведомление zlib (см. `NOTICE`).

## Как устроен образец

**Сцена карты.** `webMap.ts` читает `.map` (`DataFileReader`), отдаёт страницe JSON: группы (сдвиг, параллакс, обрезка), слои (тайлы: размер, цвет, картинка, огибающая; квады: 38 чисел на квад), картинки (имя, размер,
внешняя или встроенная), огибающие. Тайлы каждого слоя идут отдельными запросами `/api/scene/tiles/<слой>`, встроенные картинки перекодируются в PNG (`encodePng`, кэш на диске в `runs/scene-cache`) и идут
`/api/scene/image/<n>`. Особые слои (tele, speedup, switch) сжимаются в записи «разрыв + поля».

**Рисование.** Canvas 2D (`webView.ts`, 2100 строк): слои собираются в «проходы» (`buildPasses`), тайлы рисуются в чанки-канвасы с уровнем детализации (`chunkLod`) и кэшируются; цвет слоя достигается
перекраской чанка (`multiply`); квады — аффинным приближением по трём углам (`affine3`) или узором; огибающие считаются `envEval` и применяются к цвету и позиции; камера и параллакс — `groupView` (копия
`IGraphics::MapScreenToWorld`). Рисуют до игрового слоя, потом тии, потом передний план; «сущности» — тайлсетом `editor/entities_clear/ddnet.png`.

**Тии.** Скин `skins/<имя>.png` (если нет — `skins.ddnet.org`), перекраска как `CSkins::LoadSkin` (`skinColorable`, `skinTint`, цвета `ddnetColor`), позы из `ANIMS` (`teeAnimFor`), тело, ноги, глаза, оружие,
крюк (цепь по 24 единицы), полосы заморозки (`freezeBarPieces`), снежинки, эмоции, имена (`renderPlates`), HUD (оружие, прыжки, значки состояний), табло (`boardMetrics`, `boardColumns`), лента «заморожен».

**Графика** (`webAssets.ts`): ищет папку `data` DDNet по десятку мест на машине пользователя, иначе скачивает `game.png`, `emoticons.png`, `extras.png`, `hud.png`, `particles.png`, `arrow.png`, `mapres/*.png` с
GitHub и скины с `skins.ddnet.org` в кэш `runs/`. Шрифт DejaVu Sans оттуда же.

**Вид.** `page.css`: фон `#99a3c5` с движущимся шахматным узором (`conic-gradient`) и виньеткой, панели `rgba(0,0,0,.25/.5)`, карточки с тёмной шапкой, кнопки `rgba(255,255,255,.5)`, шрифт DejaVu Sans 13,5 px,
иконки Lucide, вкладки сверху с закруглёнными углами; «Игра»: сетка «экран | колонка» (состояние, игроки, журнал); окно по высоте экрана, прокрутка внутри панелей. Снимки: `game.png` (экран с HUD и лентой),
`window.png` (окно целиком), `scoreboard.png` (табло поверх игры), `mini.png` (мини-вид).

## Что мы портируем и что делаем иначе

| | образец | у нас |
|---|---|---|
| где разбирается карта | TypeScript на сервере | **Rust** (`ddai-map::scene`), формат `DWSC` (`docs/formats.md` §35), один запрос на карту |
| отрисовка | canvas 2D, чанки, аффинные квады | **WebGL2**: слой тайлов — один четырёхугольник и шейдер, массив из 256 текстур, настоящие квады (D-093) |
| графика DDNet | ищется на диске пользователя или скачивается из сети | **только с локального каталога** `--ddnet-data`, через закрытый список `/assets/…`; сети нет; в git не входит |
| скины | `skins.ddnet.org` для неизвестных | нет скина — `default` |
| камера, параллакс, огибающие, позы, перекраска скинов, полосы заморозки, табло | свои реализации по DDNet | **портированы** (те же формулы, `ddmap.js`, `ddtee.js`, `game.js`) |
| чат | журнал + ввод владельца | **только чтение**, недоверенный ввод, кольцо в памяти; бот не пишет (D-007) |
| вид бота владельца | свой тий выделен именем | кольцо, плашка «БОТ», золотой ник, стрелка у края |
| вид страницы | меню DDNet: сине-серый фон, стеклянные панели | то же; вкладки снизу на телефоне; панели «Бот», «Муха», «Обучение» не менялись |

Не берём: управление ботом из окна образца, запись клипов, звук, режим «мини», Electron-обвязку, иконки Lucide (нужен лишь текст и несколько значков, рисуем без них).

## Что нашли по дороге

- Карта `blmapV3ROYAL` называет **внешние** картинки `../skins/greyfox` и `../skins/saddo`: имя из карты нельзя склеивать с путём (сервер отдаёт только простые имена, страница таких не запрашивает, тест на это есть).
- На десяти картах из кэша нет ни одной безье-огибающей; безье в DDNet хранится в отдельном UUID-элементе — читаем как линейную.
- В DDNet 20.1 (а не в 20.0 образца) слой speedup рисуется только листом стрелок `editor/speed_arrow_array.png` (индекс — угол % 90, поворот по четверти), слой tune — цветовой текстурой; рисуем speedup, tune пропускаем.
- `glTexSubImage3D` с `UNPACK_SKIP_ROWS` требует заданного `UNPACK_IMAGE_HEIGHT` — иначе `INVALID_OPERATION` (нашли на Chromium/ANGLE).
