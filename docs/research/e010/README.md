# E-010 (задача 3.6): сырые материалы замеров

Инструменты и результаты, на которые ссылается `docs/EXPERIMENTS.md` E-010. Скрипты — рабочие черновики с путями этой VM (`~/aiddnet/wt/task-3.6`,
`~/aiddnet/data/runs/E-010/`), не часть сборки.

- `sampler-profile.patch`, `profile.sh` — выборочный профиль по меткам фаз (`perf` на VM закрыт): патч добавляет `ddai_physics::sampler` и метки, `ddnet-ai`
  получает поток-сэмплер при `DDAI_SAMPLE=1`. Патч снят с дерева до ускорений: на итоговом дереве часть хунков не ложится, `profile.sh` ставит пропавшие
  метки вручную и после сборки возвращает дерево. `prof-vs-planner.toml` — нагрузка; `groups.py` сворачивает метки в группы; `prof2.txt` (до) и
  `prof-v6b.txt` (после шага v6) — исходные счётчики.
- `ab.sh` — интерливинг старого и нового тестовых бинарников `hybrid_speed` (`calibration_report`), `ab-final.txt` — итоговый замер.
- `cmp.py`, `identity.sh` — побитное сравнение прогонов арены (хэш решений, тик конца, счётчики работы; времена исключены), `parity.sh` — набор паритетов.
- `mcnemar.py` — парное сравнение OLD/NEW (засчитанные, Уилсон, точный McNemar); `strength.md`, `threat.md`, `crowd.md` — его вывод.
