# Скриншоты для README / Screenshots for the README

Снимки сделаны 2026-10-04 (`game-zoom.png`, `game-wide.png`, `bot-tab.png` и `status-tab.png` сняты заново 2026-10-05, задача 5.11: под чатом вкладки «Игра» стоит поле ввода, на «Боте» вместо него указатель, на «Статусе» настоящее состояние бота; сервер 127.0.0.1:8453) браузером Chromium (Playwright, программный WebGL) с тестового экземпляра `ddnet-ai web` на
`127.0.0.1`. Игра шла на **частном сервере DDNet 20.1** (`127.0.0.1`, `sv_register 0`, карта Copy Love Box): бот `Muha`
(`--brain hybrid --fly-bundle <E-005> --web-names`) и три скриптовых спарринг-партнёра `Spar1`…`Spar3`. Других игроков, адресов, паролей и
имён серверов на них нет. После съёмки PNG сжаты палитрой (libvips/imagequant).

The screenshots were taken on 2026-10-04 (`game-zoom.png`, `game-wide.png`, `bot-tab.png` and `status-tab.png` were retaken on 2026-10-05, task 5.11: the chat input now sits under the chat on the Game tab, the Bot tab has a pointer to it instead, and the Status tab shows the bot's real state; server 127.0.0.1:8453) with headless Chromium (Playwright, software WebGL) from a test `ddnet-ai web` instance on
`127.0.0.1`. The game ran on a **private DDNet 20.1 server** (`127.0.0.1`, `sv_register 0`, the map Copy Love Box): the bot `Muha` and three
scripted sparring partners `Spar1` to `Spar3`. No other players, addresses, passwords or server names appear. The PNGs were palette-compressed afterwards.
